#   Herb Veda – AI-Powered Ayurvedic Assistant

Herb Veda is an AI-powered Ayurvedic healthcare assistant that provides simple Ayurvedic guidance and home remedies through an interactive web application.

##   Features

*   AI-powered Ayurvedic chatbot **Granny**
*   Herbal medicine information
*   Wellness quizzes
*   Voice-enabled interaction
*   Personalized Ayurvedic guidance
*   Responsive web interface

##   Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* Ollama
* Llama 3

##   AI Chatbot

The Granny chatbot uses **Llama 3 through Ollama** to generate simple Ayurvedic responses to users' questions.

##   Run Locally

```bash
git clone https://github.com/VaishnaviDiksangi16/DV-HerbVeda-Ayur1605.git
cd DV-HerbVeda-Ayur1605
cd herbveda
pip install -r requirements.txt
python manage.py runserver
```
